#### Redis数据结构和常见应用场景
Redis是个高性能的键值存储系统，支持多种数据结构
1. String 字符串
最简单的类型数据类型 存储字符串、整数或者浮点数
应用场景：作为缓存存储简单的键值对数据，实现计数器比如统计访问量，存储用户会话信息比如登录状态

2. Hash 哈希
键值对集合，适合存储hash对象
应用场景：存储对象比如用户信息、商品信息

3. List 列表

4. Set 集合

5. ZSet 有序集合

剩余还有一些比较高级的数据结构比如位图、geo等等目前没有接触过
